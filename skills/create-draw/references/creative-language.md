# 创意语言库

评图与概念生成的"内功"。图上的线条只有配上这套语言才成立。
原则：**每句话必须有判断**——能同时套在任何一张图上的话（"色彩可以更协调"）不许写。

## 〇、两个先行动作（一切评图与概念的起点）

1. **志向先行**（评图用）：动笔前先用一句话立出"这张图想成为什么"
   （它的 ambition）。全部意见相对志向给——帮它成为更好的自己，
   而不是换成我喜欢的另一张图。脱离志向的批评只是趣味之争。
2. **张力先行**（概念/方向用）：先写出这个项目的核心张力——
   业主想要的 × 场地给的、气质 × 功能、预算 × 野心，至少一组。
   **每条创意方向必须能回答"它解决哪个张力"**；解决不了任何张力的方向再好看也砍掉。

## 一、评图五维（每维一句有判断的话）

| 维度 | 看什么 | 判断句式示例 |
|---|---|---|
| 构图 | 视觉焦点唯一性、视平线高度、前中后景层次、留白 | "焦点被吊灯和背景墙争夺，画面无主，建议弱化其一" |
| 材质 | 材质数量（>4 种即嫌多）、质感真实度、冷暖搭配 | "五种木色互相打架，收敛到一深一浅" |
| 光影 | 光源逻辑、明暗节奏、有无'光的动作'（洗墙/聚焦/剪影） | "满屋均亮如展厅，缺一处暗下来的角落，空间没有呼吸" |
| 色彩 | 主色占比（70/25/5 法则）、饱和度纪律、色温统一 | "主色不足六成，5% 的强调色又太散，撞色失去力量" |
| 风格锚点 | 当前最接近哪个谱系、锚点是否成立、有无杂糅 | "上半身 Van Duysen 下半身轻奢，腰线以下背叛了概念" |

## 二、风格谱系与大师锚点

给方向必须落到具体的人或谱系上——"高级感"不是方向，"往 Zumthor 的光走"才是。

| 谱系 | 锚点人物/事务所 | 识别手法（画图时可直接引用的动作） |
|---|---|---|
| 静奢/静默 | Vincent Van Duysen, John Pawson | 消隐门框、同色低对比、天光洗墙、家具贴地 |
| 侘寂/时间感 | Axel Vervoordt | 灰泥肌理、旧木、器物孤置、大面留白、光影斑驳 |
| 光与体量 | 安藤忠雄, Peter Zumthor | 光缝切入、清水混凝土、材料的重量感、序列压缩再释放 |
| 叙事/新东方 | Neri&Hu 如恩 | 场景蒙太奇、金属网帘、旧城肌理引用、内窗对望 |
| 法式当代 | Joseph Dirand | 石材冷冽、线脚抽象化、黑色点睛、克制的古典比例 |
| 意式当代 | Piero Lissoni, Studiopepe | 色块构成、curated eclectic、艺术品作为句读 |
| 戏剧/新装饰 | Kelly Wearstler | 大胆拼石、雕塑家具、撞色纪律、镜面与曲线 |
| 人本温度 | Ilse Crawford | 可坐可躺的尺度、织物层次、暖光低位、"设计为感受服务" |

杂糅不是罪，无意识的杂糅才是。指出杂糅时说清"哪个部位属于哪个谱系"。

**锚点库**：上表只是索引。每个谱系在 `references/anchors/<slug>/` 有独立文件夹——
`anchor.md` 是详细手法与判断口径，旁边的 jpg/png 是用户积累的视觉锚（文件名即标签）。
匹配到方向后**先读对应 anchor.md**；文件夹里有图就把图排进方向板用图说话。
新增谱系的方法见 `anchors/README.md`，用户随时可自己建文件夹丢图，无需登记。

## 三、光的处理手法（橙色 hatch/引线 在图上标这些动作）

天光缝（切开屋顶或墙顶的一线天）· 洗墙（光贴面下滑显肌理）· 点聚焦（黑暗中只亮器物）·
漫反射盒子（见光不见灯）· 剪影（逆光轮廓）· 格栅影（光被切成节奏）· 低位光（光从脚边来，
空间变静）· 烛级照度（餐饮/酒窖的仪式感）。
评图时先问：这张图里**光做了什么动作**？没有动作，就把"给光一个动作"作为第一条创意方向。

## 四、材质情绪表（给替换建议时带上情绪理由）

微水泥/灰泥=静、吸声般的安静 · 石灰石/洞石=冷静的仪式 · 胡桃木=沉稳叙旧 ·
白橡=清晨感 · 黄铜（做旧）=时间的温奢 · 不锈钢=锋利当代 · 亚麻/羊毛=体温 ·
玻璃砖/长虹玻璃=朦胧的分寸 · 火山岩/夯土=原始重量。
句式："A→B"不够，要"A→B，因为空间需要从 × 情绪转向 × 情绪"。

## 五、创意方向句式（每次给 2~3 条，宁少勿泛）

**改法（动词开头，可执行）+ 参照（大师/项目/谱系）+ 预期效应（空间会发生什么）**

- 例："取消灯带改磁吸轨道+两盏 spot，参照 Van Duysen 的静默天花——顶面退场，视线还给墙上的光斑。"
- 例："入口压低至 2.2m 再进入 4.5m 通高，借 Zumthor 的序列压缩——仪式感不靠对称靠身体感受。"

三条方向之间要拉开档位：一条**收**（做减法回到纪律）、一条**进**（深化现有气质）、
一条**破**（换一个谱系试探）——用户挑的不是对错，是胆量。
三条必须用**不同的创意方法**生成（见第六节轮盘），否则很容易是同一思路的三种说法。

**每条方向附一句死穴**（pre-mortem）：它最可能死在哪一环（预算/工艺/业主接受度/
与功能冲突）。推荐哪条就要说清"这条赌的是什么"。敢写死穴的方向才可信。

**情绪三档**（方向要瞄准第三档）：
好看（转瞬即忘）< 舒服好用（住着记得）< **被触动**（离开后会讲给朋友听）。
每个概念必须指出"客人离开后会向朋友描述的那一幕"是什么——说不出这一幕，
说明方向还停在前两档。

## 六、创意方法轮盘（生成方向时轮换使用，一条方向一种方法）

| 方法 | 动作 | 何时用 |
|---|---|---|
| 反转 | 把最大的缺点扶正为主角 | 场地有"硬伤"（低矮/无窗/异形柱）时 |
| 移植 | 从另一种空间类型借原型 | 气质卡壳时（酒窖←教堂、书房←茶室、入口←山门） |
| 极化 | 把已有的一个特质推到极限 | 方案"什么都有一点"、平庸时 |
| 减法 | 拿走一个理所当然的元素 | 图面太满时（没有吊顶？没有主灯？没有电视墙？） |
| 蒙太奇 | 新旧/粗细/贵贱并置制造电流 | 改造项目、有历史层的场地 |
| 仪式化 | 给一个日常动作设计仪式 | 需要记忆点时（进门、洗手、开一瓶酒） |
| 尺度错置 | 把一个元素放大/缩小到失常 | 空间无戏剧性时（一盏过大的灯、一门过小的洞） |
| 时间叠印 | 让材质呈现"会变老"的属性 | 业主怕过时、追"永恒感"时 |

方法是引擎不是标签——交付物里不出现方法名，只出现它生成的方向。

## 七、方向自评（轻量三分制，反通胀）

给三条方向各打一行分：**张力解决度 / 落地性 / 被讲述的潜力**（各 1~3 分）。
纪律：三条方向**禁止同分**；总分最高者才可作为推荐，且推荐语必须包含它的死穴。
需要更严的量化（多维加权、逐轮追踪）就衔接 moodboard-aesthetic-iteration，不在这里重造。

## 八、概念生成流程（场景二的思考骨架）

1. **关键词消化**：用户给的词（如"幽暗、仪式、石"）各自翻译成一个空间动作；
2. **立张力**（第〇节）：写出本项目的核心张力，概念必须回应它；
3. **概念主张**：一句话，有立场，可被反驳（"这不是酒窖，是一座往下走的教堂"）；
4. **空间原型**：用图元画抽象原型——序列（箭头）、明暗分区（气泡）、光的动作（橙带）、
   视线（虚线）；原型必须能被一句话复述；
5. **三策略**：光/材质/动线各一条，均带锚点；
6. **那一幕**：指出"客人离开后会向朋友描述的一幕"（第五节情绪三档的第三档）；
7. **锚点声明**：本概念站在哪个谱系肩上，与它的差异在哪；
8. **推演钩子**：留出"如果往 × 走会变成 V2"的口子，衔接概念推演场景。

## 九、红队自检（交付前问自己）

- 把项目名遮住，这些意见还成立吗？成立说明写泛了，重写。
- 三条创意方向是不是同一个方向的三种说法？是就砍掉两条另想（方法轮盘换引擎）。
- 大师参照是装饰还是论据？说不出"参照的具体手法"就删掉这个名字。
- 推荐的方向写死穴了吗？没写就是在推销，不是在判断。
- 评图意见是否都服务于图自己的志向？夹带了我的趣味私货就删。
