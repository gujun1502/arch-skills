# 光与体量（安藤忠雄 · Peter Zumthor）
适用场景：品鉴室、纪念性空间、独栋、下沉空间
关键词：光缝、重量、序列、压缩与释放

## 识别手法
- 光缝切入（顶缝/侧缝），光是唯一的装饰
- 清水混凝土/整石，材料自带重量感
- 序列压缩再释放：低暗窄 → 高亮阔的身体经验
- 照度纪律：大部分区域敢于暗下来

## 判断语言
- 什么样算"对"：闭上眼能复述"身体走过的明暗节奏"
- 常见的假模仿：清水混凝土墙上开普通窗、打满射灯——有材料没有光的动作

## 偷法（偷结构不偷皮）
- 可偷：序列压缩-释放的身体经验设计；"敢暗"的照度纪律；光缝作为唯一装饰的克制
- 不可偷：清水混凝土表皮本身——工艺不到位就是水泥毛坯房

## 它解决什么张力
- 仪式感 × 反装饰：要庄重但业主厌恶一切"装饰出来的隆重"
