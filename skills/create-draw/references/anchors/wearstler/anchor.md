# 戏剧/新装饰（Kelly Wearstler）
适用场景：酒店、会所、零售
关键词：拼石、雕塑家具、撞色纪律、曲线

## 识别手法
- 大胆拼石（多色大理石几何拼）
- 雕塑感家具，形体夸张但材质高级
- 撞色有纪律：高饱和只出现在可移走的物件上
- 曲线与镜面制造舞台感

## 偷法（偷结构不偷皮）
- 可偷：撞色纪律（高饱和只放在可移走的物件上）；拼石的几何组织逻辑
- 不可偷：直接复刻其拼石图案——辨识度太强，抄了就是抄了

## 它解决什么张力
- 要出片传播 × 不能俗：商业空间既要视觉爆点又要经得起同行看
