# 人本温度（Ilse Crawford）
适用场景：民宿、长者空间、家庭住宅、餐饮
关键词：体温、织物、低位光、可坐可躺

## 识别手法
- 一切从身体感受出发：座面高度、扶手触感、光的位置
- 织物层层叠叠（亚麻、羊毛、灯芯绒）
- 暖光低位（台灯/壁灯），几乎不用顶光
- 材料要"越用越好看"（黄铜、皮革、原木）

## 偷法（偷结构不偷皮）
- 可偷：从身体感受倒推设计的流程（先定坐感/光位/触感，再定造型）；低位暖光的布光法
- 不可偷：某个具体的"温馨样板间"陈设——温度来自尺度与光，不来自摆件

## 它解决什么张力
- 设计感 × 生活气：怕"太设计"住着累，又不甘心平庸
