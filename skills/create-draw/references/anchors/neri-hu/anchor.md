# 叙事/新东方（Neri&Hu 如恩）
适用场景：精品酒店、餐饮、城市更新、文化空间
关键词：蒙太奇、内窗、金属网、旧肌理、对望

## 识别手法
- 场景蒙太奇：新体量插入旧结构，缝隙处讲故事
- 内窗与夹层制造"看与被看"的对望关系
- 金属网帘、黑钢框，工业构件做柔性分隔
- 引用地方旧肌理（砖、瓦、里弄尺度）但不复古

## 偷法（偷结构不偷皮）
- 可偷：新体量"插入"旧结构的叙事手法；内窗制造的对望关系；工业构件做柔性分隔
- 不可偷：黑钢+金属网的表皮堆砌——没有新旧对话的场地用这套就是造假古董的反面

## 它解决什么张力
- 保留历史 × 植入当代功能：城市更新和老建筑改造的核心矛盾
