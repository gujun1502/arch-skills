# 锚点库使用与扩充规则

每个谱系一个文件夹，里面放两类东西：

```
anchors/
├── van-duysen-pawson/
│   ├── anchor.md        ← 文字：手法语言（给模型评图/给方向时引用）
│   ├── 01-天光洗墙.jpg   ← 图片：视觉锚（会被直接排进概念板/方向板/推演画布）
│   └── 02-消隐门框.png
└── ...
```

## 新建一个谱系（三步）

1. 在本目录下建文件夹，命名用小写短横线（如 `wabi-modern`、`shanghai-artdeco`）；
2. 放一个 `anchor.md`，照下面模板写（可以让模型代写初稿再自己改）；
3. 丢参考图进去，**文件名带语义**（如 `03-烛级照度餐区.jpg`）——文件名就是图的标签，
   模型排图时直接拿它当说明文字。

## anchor.md 模板

```markdown
# 谱系名（锚点人物/事务所）
适用场景：……（住宅/酒店/餐饮/展陈…）
关键词：……（3~6 个）

## 识别手法（画图时可直接引用的动作）
- 手法一：……
- 手法二：……

## 偷法（Steal——借这个谱系时，偷结构不偷皮）
- 可偷：……（背后的空间机制，换材质换语汇仍成立的那部分）
- 不可偷：……（一模一样照搬就穿帮的标志性表皮）

## 判断语言（评图时的口径）
- 什么样算"对"：……
- 常见的假模仿：……
- 它解决什么张力：……（这个谱系天生擅长化解的那对矛盾）
```

## 模型使用规则

- 评图/概念生成前，按方向匹配 1~2 个谱系，读其 `anchor.md`；
- 文件夹里**有图片就优先用图说话**：`c.image(图片路径, x, y, w=…)` 排进方向板，
  配的文字不超过一句引领语；没有图片才退回纯文字引用手法；
- 用户新加的文件夹/图片无需登记，每次任务时用 Glob 扫 `anchors/*/` 现状即可；
- 图片仅限本地参考用途，不外发、不上传。
