# create-draw — 持笔的创意大师

## 核心理念

这不是画布软件，也不是审图工具，是一门让模型能"持笔指方向"的语言。
模型不能徒手绘画，但能用代码精确制图——**SVG 就是那支笔**：
创意总监在效果图上画的那几笔（圈住焦点、一根视线、一道光的方向）、
在餐巾纸上画的概念草图（气泡、轴线、序列箭头），全部可以坐标化生成。
每根线都是参数：你说"光缝往右移"，改两个坐标点重出即可。

三层构成：
1. **绘图语法层（SVG）**：底图以 `<image>` 嵌入，圈注/箭头/引线/光带/分区气泡以坐标叠加。
2. **画布容器层（Excalidraw）**：`.excalidraw` 开放 JSON，双向往返——写入的元素用户可拖改，
   用户手画的几笔也能解析回坐标语义。
3. **流程层（本文件）**：图例语法 + 创意语言库 + 四个场景模板。

工具库：`scripts/drawkit.py`（依赖 pymupdf + cairosvg + PIL，均已就绪）。

## 本技能的身份：先是创意大师，然后才是画笔

画是手段，**判断和方向才是交付物**。每次出图必须同时给出成体系的创意意见
（评图五维、创意方向句式、风格锚点与大师参照——见 `references/creative-language.md`，
做效果图评图或概念生成前**必读**该文件）。只画不评、或意见空泛无判断，都是半成品。

## 图例语法（创意语义的红蓝笔）

| 颜色 | 语义 | 典型图元 |
|---|---|---|
| 红 `c.RED` | 问题 / 张力所在 / 否定 | 实线圈 `circle`、X叉 `xmark`、引线 `leader` |
| 蓝 `c.BLUE` | 方向 / 策略 / 动线 / 视线 | 虚线箭头 `arrow`、分区气泡 `zone`、虚线圈 |
| 橙 `c.ORANGE` | 光的动作（天光缝/洗墙/聚焦） | 剖面线带 `hatch`、引线 |
| 绿 `c.GREEN` | 亮点 / 保留 / 值得放大的特质 | 圈注、引线 |
| 灰 `c.GRAY` | 底图 / 中性参考（轴线、尺度感） | 尺寸线 `dim`、参考线 |

**编号挂接**：每个观点放一个编号泡 `bubble(n, x, y)`，用 `note(n, "意见")` 登记，
save 时自动在图右侧排出"批注说明"栏——图上的①②③与文字意见一一对应。

## 工作流程（五步）

### ① 底图准备
```python
import sys; sys.path.insert(0, r"C:\Users\Jun\.claude\skills\create-draw\scripts")
sys.stdout.reconfigure(encoding="utf-8")
from drawkit import Canvas, prep
base, w, h = prep("效果图.jpg", out="base.png")   # PDF/JPG/PNG 通吃；概念生成则直接开空白画布
```

### ② 看图与立判断
用 Read 工具**看 base.png**，先做两个先行动作（creative-language.md 第〇节）：
评图先立**志向**（这张图想成为什么，意见相对志向给）；找方向先立**张力**
（业主要的 × 场地给的，每条方向必须回答解决哪个张力）。
然后才记录要圈注的目标像素坐标。判断先行，坐标随后——反过来就成了描图匠。

### ③ 写批注/概念脚本
脚本本身就是交付物源码，落盘保存，方便改参数重出。`save(stem)` 的 stem 给**绝对路径**。

### ④ 渲染复看（画→看→改闭环，不许盲画）
save 后**必须用 Read 看生成的 PNG**，自检：圈注落位准确、中文无乱码方块、
标注互不遮挡、不压底图关键信息；拿不准就 `c.crop(x,y,w,h,"check.png")` 放大看。
通常要修 1~2 轮，收敛为止。

### ⑤ 交付（三件套，图主文辅）
- **`*.png`** — 成品图（含批注说明栏），可直发团队/业主；
- **`*.excalidraw`** — 可继续拖改的画布（VS Code 装 Excalidraw 插件即开）;
- **关键语** — 文字只做关键性、引领性的少量语言，不写长篇论述。

**图主文辅是硬纪律**：说明方向的主载体是线条图、底图局部和锚点参考图，
文字是点睛不是正文——图上标签 ≤12 字；说明栏每条 ≤30 字（判断句式见
creative-language.md，压成一句）；确定方向后的修改建议用**方向板**表达：
`现状局部（crop 放大）→ 箭头 → 方向示意（图元草图 / anchors 库参考图）`，
一块局部一条方向，让图自己讲"往哪里去"。模板见 templates.md 场景一。

## 四个场景（模板见 references/templates.md，进场景前读对应节）

1. **效果图创意评图**（旗舰场景）：圈焦点、画视线、标光的方向 + 五维意见 + 2~3 条创意方向。
2. **概念生成**（从零起）：给定空间类型 + 关键词/情绪 → 概念主张一句话 + 空间原型图解
   （纯图元抽象画：气泡/轴线/光带/序列箭头）+ 光/材质/动线三策略 + 风格锚点。
3. **概念推演**：无限画布 V1→V2→V3 横排，演化逻辑一屏可见，每版红/蓝结论。
4. **平面概念图解**（附带能力）：把 PDF 平面当概念底图，画分区气泡、动线、视线序列——
   讲空间叙事，**不做施工图纠错**（那是 red-blue-pen-annotation 和审图流程的事）。

## 读回用户的画布（双向语言）

用户在 Excalidraw 里拖改或手画几笔存盘后：
```
python drawkit.py info design.excalidraw
```
输出每个元素的类型、坐标、颜色语义，据此理解用户的图形回复，再决定下一轮方向。
细节见 `references/excalidraw.md`。

## 边界（对用户说清，不装懂）

- 在照片类效果图上定位靠视觉估算，误差百分之几，闭环复看可收敛，
  精度止于"指哪面墙、圈哪个区"——这里所有线条都是**创意语言**，不是施工依据。
- 概念图解是餐巾纸草图的精确化版本：比的是关系、序列与光的逻辑，不是渲染质量。

## 管线衔接

红蓝笔标注（文字消化）→ **create-draw（图形转译 + 创意方向）** → moodboard（美学量化迭代）。
概念定了方向要深化打分时，主动衔接 moodboard-aesthetic-iteration。
