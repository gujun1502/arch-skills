# 概念引擎 —— 让设计构思耳目一新且能被记住

> 这个业态的概念之所以普遍平庸，是因为大家都从"企业价值观"出发（稳健、专业、进取），
> 而价值观是**没有形状的**。本引擎强制从**无形之物 → 具体意象 → 空间手法 → 一条几何线**
> 四步落地，任何一步说不出来，概念就不成立。

---

## 一、四步引擎

### 第一步：锚 —— 这家公司卖的无形之物是什么

不是问"你们公司什么价值观"，是问四个更硬的问题：

1. **你们管的是谁的钱？管多久？**（LP 的钱、10 年封闭期 → 卖的是"长期"）
2. **客户为什么选你们而不是隔壁？**（判断力？关系？退出记录？）
3. **成交是在哪个房间里发生的？**（那个房间就是全案要投最多钱的地方）
4. **你们最怕客户觉得你们怎么样？**（怕显得穷？怕显得浮夸？怕显得不专业？
   **这条最有用——空间要解决的是恐惧，不是愿景。**）

输出：**一句话内核，≤12 字**。

| 子业态 | 常见内核 |
|---|---|
| PE/VC | 「我们看得比你远」「时间站在我们这边」 |
| 券商资管 | 「秩序即安全」「每一笔都被看见」 |
| 律所 | 「站在你和风险之间」「白纸黑字」 |
| 家办/私行 | 「三代人的事」「不被打扰」 |
| 国资产融 | 「把地方的资源接到资本上」 |
| 量化 | 「让概率在这里发生」 |

---

### 第二步：象 —— 什么具体原型能承载它

**规则：必须是名词，必须能被摸到或看见，不能是形容词。**

坏例子：融合、生长、律动、赋能、共生。
好例子：潮汐、年轮、账簿的页边、日晷、矿脉、河床、沙漏里的那一颗、
密码本、渔汛、堤岸、灯塔的旋光、天平的支点、种子库、航海图上的经纬线。

**三个可靠的取象来源**（按优先级）：
1. **场地/城市文脉**——青岛→潮汐与海浪（国信）；北京→院落与光；上海→外滩的层与线。
   *这是最安全也最容易被业主接受的一路。*
2. **企业 VI/名称的字面义**——植德的"树"（Merits **Tree**）；弘毅的"弘"（宽广）。
   *这是最容易被记住的一路。*
3. **业务动作本身**——尽调（层层剥开）、退出（一次跃迁）、封闭期（沉淀）、
   路演（被注视）、复利（同心圆的扩散）。
   *这是最锐利、最容易做出新意的一路，也最需要设计功力。*

---

### 第三步：法 —— 用哪一个空间手法把它做出来

从 `spatial-devices.md` 的 14 个手法里选**一个**（只能一个）。
选的标准：**这个手法能不能在没有装饰的情况下独自成立？**

如果一个概念需要靠"再加个装置"才能被看懂，它就没通过第三步。

---

### 第四步：形 —— 那条唯一的主导线是什么

三选一：**一条弧**（R ≥ 6 m）/ **一条斜**（15°–30°）/ **一次折**。

这条线要能在平面上画出来，且同时是天花线、灯带、分区界、动线转折（宪章 §9）。

---

## 二、合格线：一句话公式

> **动词 + 材料 + 空间事件**

| 案例 | 一句话 |
|---|---|
| Antares | *用一部黑钢浅木的悬挑楼梯，把两层人的目光缝在一起* |
| 国信 | *用一条自由曲线的光，把海的潮汐画在整层楼的顶上* |
| 植德 | *用一根丝，把法律的公正和品牌的那棵树说完* |
| 弘毅 | *用一片木的弧，把方正的楼层卷成有前后的空间* |

**自检四问**（全中才算概念）：
1. 能用上面的公式说清？
2. 在平面上画得出来？
3. 只需要一条主导线？
4. 董事长能在电梯里向别人复述？

## 三、12 个资管空间原型概念（发想弹药库）

用法：**不要直接抄**。拿它们当"这个方向长什么样"的样本，
用四步引擎重新跑一遍业主自己的内核。

---

### 1. 「复利」—— 同心的扩散
**内核**：时间站在我们这边。
**象**：水面的涟漪 / 年轮 / 复利曲线。
**法**：同心弧墙 + 同心灯带（宪章 §9 的偏移复制）。
**形**：一组圆心在前台的同心弧，越往里越疏。
**空间事件**：从电梯出来，天花上的弧一圈一圈向你扩散，走到中心就是接待台。
**落地**：3–4 条同心弧灯带（间距 1200 → 1800 → 2700 mm，等比放大），
弧内侧木饰面，弧外白平顶。造价 A 档可控。

### 2. 「尽调」—— 层层剥开
**内核**：我们看得比你远。
**象**：地层剖面 / 矿脉。
**法**：材料的**分层横带**（地平线式水平分层，越往上越轻）。
**形**：一条贯穿全场的水平线（标高 1100 mm 或 2100 mm）。
**空间事件**：所有墙面在同一标高被一条黑缝切开，缝以下是石与深色，缝以上是木与白。
走廊尽头这条缝"翻"上天花，变成灯带。
**落地**：极省钱，靠一条通长凹缝 + 上下材质切换实现。**适合造价紧的项目。**

### 3. 「潮汐」—— 光的自由曲线
**内核**：把地方的资源接到资本上（沿海城市）。
**象**：潮线 / 沙滩上的水痕。
**法**：自由曲线灯带 + 镜面地反射。
**形**：一条有张力的样条曲线。
**空间事件**：一条光在顶上游走，在镜面地上变成两条，人走在两条光之间。
**参考**：国信（已实现，谨慎复用）。

### 4. 「缝合」—— 垂直的事件
**内核**：两个团队/两个业务/两层楼要变成一个。
**象**：缝线 / 桥。
**法**：**通高楼梯**（黄金标准，见 §15）。
**形**：一条 30° 斜线。
**空间事件**：贴着落地窗上下的黑钢楼梯，楼上的人能看见楼下的人，
梯下是一片黑碎石的庭。
**参考**：Antares。**这是本技能最推荐争取的概念。**

### 5. 「账簿的页边」—— 竖线的疏密
**内核**：白纸黑字 / 每一笔都被看见。
**象**：账本竖排的行线 / 书脊。
**法**：竖向线阵的**疏密渐变**（斜切板、格栅、金属丝）。
**形**：一条从疏到密的渐变边界（线可以是直的，密度是那条"线"）。
**空间事件**：一面 20 m 长的墙，线从 400 mm 间距渐渐密到 30 mm，
最密处正好是 logo 与接待台。
**落地**：植德斜切板墙的升级版，造价 800–1,500 元/㎡。**性价比极高。**

### 6. 「封闭期」—— 一个不被打扰的核
**内核**：三代人的事 / 不被打扰。
**象**：内院 / 核 / 保险库。
**法**：**中心实体核**（把最重要的房间放在平面正中，四周环绕动线）。
**形**：一个方（或圆）的核，动线绕它一圈。
**空间事件**：走一圈才能进去；核的外表面是全场唯一的黑块面或整体发光面。
**适合**：家办、私行、并购组。

### 7. 「日晷」—— 光的时间
**内核**：长期主义。
**象**：日晷 / 影子的移动。
**法**：**光缝**（天窗或人工天光缝）+ 一条随时间移动的光带。
**形**：一条斜光缝。
**空间事件**：一天里不同时刻，光带落在不同的房间口上。
**落地**：无天窗时用可编程线性灯模拟（Ra≥95，色温随时间 2700→4000K）。

### 8. 「路演」—— 被注视的房间
**内核**：让判断被看见。
**象**：讲台 / 环形剧场。
**法**：**下沉/抬升阶梯座席**（弘毅、国信都用了这个手法的轻量版）。
**形**：一次折（地面的抬升线）。
**空间事件**：一个可以坐 40 人的阶梯，平时是休闲区，路演时是剧场。
**落地**：阶梯高差 3 × 180 mm 即可成立，木质踏步兼座椅，是**最容易实现的"事件"**。

### 9. 「像素」—— 城市被打散
**内核**：科技 + 判断。
**象**：像素 / 屏幕 / 数据。
**法**：**内幕墙**（在原窗内侧加一层玻璃砖/玻璃格/穿孔金属）。
**形**：一片格。
**空间事件**：城市透过 3,000 块玻璃砖进来，变成一面会动的马赛克。
**参考**：弘毅。**外景一般的项目首选这一招。**

### 10. 「河床」—— 地面的引导
**内核**：资金的流向。
**象**：河床 / 冲积扇。
**法**：**地面材质的自由分界**（镜面白 vs 地毯 vs 木地板，边界是一条曲线）。
**形**：一条在地面上的自由曲线。
**空间事件**：一条"河"从电梯厅流到景观面，硬地是河、地毯是岸，家具全部落在岸上。
**参考**：国信（路演厅那张，白色镜面地与灰地毯的曲线分界）。
**落地**：几乎不加钱，只改排版。**是"零成本记忆点"的头号选项。**

### 11. 「种子库」—— 被保存的东西
**内核**：我们把东西存起来，等它长大。
**象**：种子库 / 档案柜 / 样本墙。
**法**：**一面通高的实体收纳墙**（书墙 / 样本墙 / 被投企业产品墙）。
**形**：一条水平的长线（墙本身）。
**空间事件**：一面 15 m 长、通高的木格墙，格子里放被投企业的实物/样本/年报，
每年增加一格。**空间会随企业生长。**
**适合**：VC、产业基金——比任何"荣誉墙"都高级。

### 12. 「天平的支点」—— 一次不对称的平衡
**内核**：站在你和风险之间（律所/风控）。
**象**：天平 / 支点 / 悬臂。
**法**：**大悬挑**（前台、吧台、座椅、雨篷式天花的悬挑）。
**形**：一次折。
**空间事件**：一块 4 m 长的石材/木台悬挑 2.4 m，底下是空的、发光的。
**落地**：悬挑 ≥ 1.5 m 才有戏剧性，需结构配合；造价 8–20 万元/件。

## 四、概念的三种"记得住"机制

好概念被记住靠的不是好看，是这三种机制之一：

| 机制 | 说明 | 例 |
|---|---|---|
| **身体记忆** | 人必须用身体经历它（走上去、绕过去、坐下去、摸到） | 楼梯、阶梯座席、悬挑台、内院 |
| **反常识** | 违反了对办公室的预期 | 梯下枯山水、最好的角给员工、前厅什么都没有 |
| **可复述** | 一句话能转述给没来过的人 | "他们那个楼梯贴着窗，上下楼能看见整个城市" |

**做概念时明确写出：我用的是哪一种机制。**
三种都没有的概念，无论渲染多漂亮，都记不住。

## 五、三个概念的输出格式

每次交付 **3 个概念**，结构必须一致，方便业主横向比较：

```markdown
## 概念 N：〈四字或六字标题〉

**一句话**：〈动词 + 材料 + 空间事件〉

| | |
|---|---|
| 锚（内核） | |
| 象（原型） | |
| 法（手法） | |
| 形（主导线） | |
| 记忆机制 | 身体记忆 / 反常识 / 可复述 |

**空间事件**：进门后 30 秒里发生的那件事，150 字以内，写成一段"你会…"的第二人称叙述。

**在平面上**：这条主导线怎么走，切出哪几个区。

**材料与色调**：主材 3–5 项（带规格），跳色 1 个（带位置）。

**造价影响**：相对基准 ±X%，最贵的那一项是什么。

**风险**：这个概念最可能死在哪（造价 / 结构 / 业主决策链 / 施工能力）。
```

三个概念之间必须**拉开距离**：
- 一个「稳」——最容易被通过的，风险低。
- 一个「准」——最贴业主内核的，推荐项。
- 一个「野」——有一个不可复制的空间事件，可能被砍但能定调子。

**推荐次序在报告里明说，不要让业主自己猜。**

## 六、红队自检（每份概念交付必附）

1. **最强反例**：这个概念业内有谁做过？做砸过没有？我这版凭什么不一样？
2. **最可能死在哪一环**：造价？层高/结构？业主决策链（谁会反对、为什么）？施工能力？
3. **谁有动机希望顾骏相信这个方案是对的**：自己（想做个作品）？效果图公司（好渲染）？
   甲方对接人（想向上邀功）？——**说破它。**
