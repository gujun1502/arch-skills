# 四个基准案例 · 逐案解剖

> 这四个案例是本技能的**审美锚点**。做任何概念或评审前，先在这里找到最接近的一个，
> 说清"像它哪里、不像它哪里"。
> 图片在 `cases/` 目录下，需要看图时直接读。

## 案例一 · 弘毅投资 北京办公室

**2022 / 北京 / 1,622 ㎡ / 设计：Robarts Spaces 一工**
业态：人民币+美元双币 PE 基金总部
图片：`cases/2022 弘毅投资北京办公室/Hony-Capital-Beijing-Office-1..8.jpg`

### 一句话
**用一片弧形木天花，把一个方正的甲级办公层"卷"成了有前后关系的空间。**

### 结构解剖

| 层 | 做法 |
|---|---|
| 主导线 | 一条大半径弧（R 约 12–15 m），从电梯厅一路划到景观面。天花木饰面沿弧铺，弧内侧一条连续灯槽 |
| 冷 | 白色水磨石地面（骨料细、近乎无纹）、乳白发光墙、玻璃砖幕墙、灰白地毯、黑钢框 |
| 暖 | 浅枫木/白橡木天花（全场 60% 的暖来自顶）、木前台、木卡座、木花箱 |
| 黑 | **无黑块面**。黑只在钢框玻璃隔断的框（40 mm）、家具腿、屏风框上出现，约 4% |
| 纹理（"格"） | 疏＝铝挂片天花线阵（约 200 mm）；中＝金属穿孔网屏风；密＝玻璃砖幕墙点阵 |
| 发光面 | 前厅整面乳白发光墙（约 12 m 宽），logo 悬于其上 |
| 跳色 | 无人工跳色。用绿植 + 逆光夕阳充当（自然跳色解法） |
| 主题三处 | 玻璃砖幕墙（科技/像素）· 木弧天花（人文/自然）· 发光墙 logo |

### 值得偷的三招

1. **玻璃砖幕墙做"内立面"**——把原建筑窗墙内侧再做一层玻璃砖/玻璃格，
   城市被打散成像素，既解决西晒/杂乱外景，又制造了全场最密的纹理。
   **造价不高，效果极强，适合外景一般的项目。**
2. **弧形卡座 + 阶梯座席贴柱布置**——把结构柱包进弧形木卡座里，柱子从障碍变成中心。
   （图 4：圆柱 + 弧形阶梯座席 + 绿植槽）
3. **门把手做成组合件**（图 8）——木 + 亚克力 + 不锈钢三材叠合的定制拉手。
   这是"贵不贵"的判断点：**客户唯一会用手摸的地方**。

### 不像的地方（用它当锚时要注意）
- 弘毅整体偏"柔"，几乎无黑块面，气质偏人文而非锐利。
  如果业主是券商自营、量化私募，需要把黑加到 6–8% 并做一次黑块面。
- 层高有限（约 2.9 m 完成面），造型天花高差只有约 250 mm，靠灯槽拉开层次。

## 案例二 · 植德律师事务所 上海新办公室

**2024 / 上海 / 3,200 ㎡**
业态：综合性律所（前场客户接待要求极高、后场保密要求极高）
图片：`cases/2024 植德律师事务所上海新办公室/*.jpg`

### 一句话
**用一根"丝"讲完了全部叙事——银丝是法律的公正与无私，红丝是品牌的那棵树。**

### 结构解剖

| 层 | 做法 |
|---|---|
| 主导线 | 一条弧的**两次偏移**（双弧木天花），弧心指向景观面，把人往窗边引 |
| 冷 | 白色亮面地砖（GU 70+，反射一切）、白色人造石异形前台、白墙、银丝装置 |
| 暖 | 浅橡木双弧天花、木饰面竖向斜切板墙、木饰面走道墙 |
| 黑 | 极少（< 3%）。**用品牌红替代黑做重音**——这是黑的合法变体 |
| 纹理（"线"） | 疏＝木饰面竖向斜切板（约 300 mm，切口渐变，像"树的年轮/书页"）；中＝天花灯带；密＝银丝/红丝装置（3–5 mm 丝距） |
| 发光面 | 无独立发光墙，靠亮面地面 + 弧线灯带 + 大面窗光 |
| 跳色 | 品牌红，三处，**全部是线**：前厅红丝台（三角形钢丝阵）· 茶水间台面红色沿口 · 会议室桌下红色横撑 |
| 主题三处 | 红丝装置（logo 树）· 木斜切板墙（树/书页）· 二十四节气门牌 + 节气跳色墙 |

### 值得偷的三招

1. **同一语法的冷暖二重奏**——银丝（冷、密、悬垂、通透）与红丝（暖、密、三角、实体），
   一个在前厅做"屏"，一个在 logo 墙下做"台"。
   **同一手法演两次，一次冷一次暖，是最经济也最高级的叙事方式。**
2. **斜切板墙**（图 1）——木饰面竖板做斜向切口，切口深度渐变，
   在平墙上做出光影的疏密节奏，**不用任何造型就有了纹理**。
   造价约为造型墙的 1/3。
3. **节气色系统**（图 13、16）——小会议室的一面墙给一个节气色（黄=立秋、绿=立夏），
   在通体冷白的办公层里，每推开一扇门是一个颜色。
   **把"文化主题"藏进使用中，而不是挂在墙上。**

### 不像的地方
- 植德前厅极空（图 4、6、7），近乎"什么都没有"。
  这是律所/资管的高级打法，但需要业主有胆量，也需要有足够面积（前厅 > 200 ㎡）。
- 办公区与会议室（图 12、18）明显降档（矿棉板天花、格栅灯、普通转椅）——
  **前场 S 级、后场 B 级的造价分配**，是这个业态的常规策略。评审时不要拿后场苛责。

## 案例三 · 青岛国信集团 产融办公室

**2025 / 青岛 / 3,363 ㎡ / 跨两个楼层**
业态：国资产融平台（政务接待属性 + 金融属性双重）
图片：`cases/2025 青岛国信集团产融办公室/*.jpg`

### 一句话
**一条自由曲线灯带，把"潮汐"变成了整层楼的乐谱。**

### 结构解剖

| 层 | 做法 |
|---|---|
| 主导线 | 一条**自由曲线**（非圆弧，是有张力的样条曲线）灯带，在白色天花上游走，同时是前厅/休闲/路演的分界 |
| 冷 | 镜面白色地面（GU 80+）、白天花、劈斧面浅色石墙、灰地毯、深灰石材柱 |
| 暖 | 铜色前台、浅木天花（会客/茶水）、木格栅天花（会客室）、驼色沙发与皮椅 |
| 黑 | **全场唯一一次黑块面**＝茶水吧整面黑金花大理石 + 黑色岛台 + 黑色高柜。位置在动线中段，是全曲强拍 |
| 纹理 | 用**粗糙度**代替图案：劈斧面石（极哑）· 镜面地（极亮）· 竖纹玻璃/铜丝（密）· 波纹地毯（中） |
| 发光面 | 走道整面弧形发光墙（**全案最好的一张照片**）；路演厅发光圆盘 |
| 跳色 | 铜金，三处：前台饰面 · 会客室铜丝弧墙 · 书架金属框 |
| 主题三处 | 金属雕塑 + 原石（旭日/大地）· 劈斧面石墙（大地）· 曲线灯带 + 波纹地毯（潮汐/海浪） |

### 值得偷的三招

1. **镜面地面把主导线加倍**——白色镜面地把天花的曲线灯带完整反射，
   一条线变成两条，空间高度感翻倍。
   **代价**：施工与维护要求极高（平整度 ≤ 2 mm/2 m），且只适合前场。
2. **发光弧墙做走道端景**（图 `6走道1.jpg`）——在昏暗走道里放一面 3–4 m 高的整体发光弧墙，
   人经过被剪影化。**造价约 3,000–5,000 元/㎡，是性价比最高的"高潮点"做法。**
3. **一次性黑块面的位置学**——茶水吧放在从前厅走向协作区的中段，
   它既是功能节点也是节奏重音。**黑块面必须放在动线的"换气口"上。**

### 不像的地方
- 国信有政务接待属性，大会议室（图 `3会议室2.jpg`）是长桌 + 话筒 + 高背椅的标准政务配置，
  与纯市场化资管的圆桌平等语汇不同。对民营 PE/VC 不要照搬。
- 跨两层但**图中未见通高楼梯**——这是它与 Antares 的关键差距，也是它停在 A 档而非 S 档的原因。
  → 若做类似跨层项目，**这就是升一档要补的那件事**。

## 案例四 · Antares Capital（美国）

来源：《全球证券资管办公室内设计案例集·第三辑（殿堂门厅与新经典材质 20 例）》第 19–21 页
业态：私募信贷/中间市场直贷机构
图片：`cases/Antares Capital 安塔雷斯资本/图29..34.jpg`

### 一句话
**一部黑钢浅木的悬挑楼梯贴着落地窗上下，把两层人的目光缝在了一起。**

### 结构解剖

| 层 | 做法 |
|---|---|
| 主导线 | 一条 **30° 斜线**（楼梯梯段）。天花木格栅顺它折下来，栏板顺它走，梯下枯山水折板同角度 |
| 冷 | 白色大板地砖（电梯厅/办公区）、白墙、超白玻璃栏板、黑钢 |
| 暖 | 浅枫木墙板（900 模数）、浅橡木地板（公共层）、木格栅天花、浅木楼梯踏板 |
| 黑 | 黑钢梯梁（唯一的"准块面"，但它是线的加厚）、黑色电梯门框、黑色玻璃立挺、黑色碎石景观 |
| 纹理（"线"） | **全场唯一纹理＝木格栅天花**，从平顶卷下来包住楼梯上空，走到办公区变回白平顶 |
| 发光面 | 无独立发光墙，靠 L 形连续灯槽 + 落地窗天光 |
| 跳色 | 无。用艺术品（蓝色格状画、黑白线圈画）承担色彩事件 |
| 主题三处 | 楼梯（结构即叙事）· 木格栅天花 · 电梯厅楼层标识（嵌入木板的金属数字 42/H7） |

### 值得偷的三招（这是本技能"空间手法"的黄金标准）

1. **楼梯五件套**：黑钢梁（250–350 mm）+ 浅木悬挑踏板（50–60 mm，**无踢面**）+
   超白夹胶玻璃栏板（12+12，无立柱）+ 细黑扶手（Ø40–50）+ **贴落地窗**。
   缺任何一件，楼梯就掉档。
2. **梯下不做储藏，做一个庭**（图 33、34）——浅木折板抬起一个平台，
   中间嵌一片黑色碎石（枯山水），旁边就是休息沙发。
   **楼梯下面是全场最容易浪费也最容易出彩的 10 ㎡。**
3. **天花包裹法**——木格栅天花从两层的顶棚一直"卷"下来包住楼梯上空的通高，
   把上下两层的空气"包"成了同一个房间。
   **通高不做天花包裹，就只是一个洞。**

### 其他细节
- 电梯厅（图 29）：浅木墙板 900 模数 + 黑色电梯门框 + 嵌入式楼层标识 + L 形连续灯槽。
  **一个厅里只有三种材料，一条线。** 这是"殿堂门厅"最省钱也最难做的版本。
- 咖啡吧（图 32）：一条 12 m+ 的长直吧台 + 木格栅天花斜向铺设 + 虎尾兰绿植带做软隔断。
  **用植物做隔断，比做玻璃隔断便宜且更适合协作区。**

## 四案对照速查

| 维度 | 弘毅 | 植德 | 国信 | Antares |
|---|---|---|---|---|
| 主导线形态 | 大圆弧 | 双弧（偏移） | 自由曲线 | 30° 斜线 |
| 纹理语法 | 格 | 线 | 粗糙度 | 线（格栅） |
| 黑块面 | 无 | 无（红替代） | 有（茶水吧） | 有（梯梁） |
| 发光面 | 前厅整墙 | 无（靠亮地） | 走道弧墙 | 无（靠灯槽） |
| 跳色 | 自然（绿植/夕阳） | 品牌红 ×3 线 | 铜金 ×3 | 无（艺术品替代） |
| 记忆点 | 玻璃砖幕墙 | 银丝/红丝 | 发光弧墙 + 曲线灯带 | 通高楼梯 |
| 档位 | A | A | A | **S** |
| 升档缺什么 | 一次黑重音、一个通高 | 一个发光的面 | 一部通高楼梯 | — |

**结论：三个国内案例都停在 A 档，缺的是同一样东西——一个不可复制的空间事件。**
Antares 用楼梯拿到了 S。这就是本技能在概念阶段最优先要为顾骏争取的东西。
