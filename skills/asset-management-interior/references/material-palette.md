# 材料与色调库 —— Moodboard 的弹药

> Moodboard 上写"暖木、浅灰、金属"是没有用的。
> 本库提供**可以直接进材料清单的规格**：品类、规格、光泽度、色号、造价、
> 以及"这块材料在这套美学里干什么活"。

## 四、跳色（占 2–5%，全场只允许一个）

| 跳色 | 适合 | 用法规范 |
|---|---|---|
| **品牌红** | 律所、老牌机构 | 只做线：台面沿口、钢丝装置、桌下横撑（植德三处全是线） |
| **铜金** | 国资、私行、家办 | 前台饰面 + 一处金属框 + 一件家具细节 |
| **深墨绿** | PE/VC、产业基金 | 一间会客室的整墙 + 一组单椅 |
| **普鲁士蓝 / 靛** | 券商、量化 | 艺术品 + 一片地毯 |
| **赭 / 陶土色** | 有地域叙事需求时 | 一面材料墙 + 织物 |
| **自然跳色（绿植 + 夕阳）** | 景观极好的项目 | 不用人工跳色，把绿植与逆光当颜色（弘毅） |

**跳色三律**：① 全场只有一个 ② 只出现在 3 个地方以内、每处 ≤ 2 ㎡
③ 至少一次以"线"的形态出现。

## 五、色调条模板（Moodboard ④ 格直接用）

```
■ 60%  冷白底      NCS S 0500-N / S 1002-Y      白水磨石·白墙·白天花
■ 30%  浅木暖      RAL 1013 附近 / 浅蜜色        白橡木饰面·实木地板
■  6%  黑重音      NCS S 8500-N                 黑钢框·收边缝·家具腿
■  3%  跳色        〈品牌色，注明 Pantone〉        〈三处位置〉
■  1%  金属/绿植   拉丝古铜 / 自然绿             点缀
```

**输出时必须写占比数字**，不写占比的色调条等于没做。

## 六、光的规格（Moodboard ⑥ 格直接用）

| 项 | 规格 |
|---|---|
| 色温 | 3000K（暖木区）/ 3500K（冷白区）；**全场 ≤ 2 种** |
| 显色 | **Ra ≥ 95**（木饰面与皮革靠它活着；Ra < 90 木头发灰） |
| 前厅照度 | 200–300 lx（低于办公区，**故意的**：暗一点才贵） |
| 办公区 | 300–500 lx（桌面），UGR ≤ 19 |
| 会议室 | 300–500 lx 可调，视频会议需人脸垂直照度 ≥ 300 lx |
| 走道 | 100–150 lx，**靠端景发光面提供方向感** |
| 灯带 | 宽 10–25 mm，连续无断点，转角 R ≥ 150 mm |
| 发光面 | 1500–3000 cd/m²，均匀度 ≥ 0.85 |
| 洗墙灯 | 距墙 300–450 mm，30° 入射（材料墙必须配） |
| 调光 | 前场全场 DALI/0-10V 可调；至少 3 个场景：接待日常 / 高规格接待 / 夜间 |

**一句判据**：如果晚上关掉所有筒灯，空间还能靠"一个发光的面 + 一条灯带"
成立，那么光就做对了。
