# 资管类办公 Benchmark —— 大局判断力

> 用途：拿到一个项目，先在这里定位它的**子业态、面积配比、造价档位、气质坐标**，
> 再谈美学。定位错了，再好的概念也是错的。
> 数据口径：中国一线/新一线城市甲级写字楼，2025–2026 年，含税，不含土建与幕墙。

---

## 一、六个子业态与它们的空间性格

| 子业态 | 客户是谁 | 空间要解决的核心矛盾 | 性格关键词 |
|---|---|---|---|
| **私募股权 / 创投（PE/VC）** | 被投企业创始人、LP | 既要显得有钱有判断力，又不能显得挥霍（LP 会介意） | 克制、内敛、有品位的低调 |
| **券商资管 / 公募基金** | 机构客户、监管 | 合规展示 + 交易强度 + 大量会议 | 秩序、效率、清醒 |
| **律所** | 企业客户、高净值个人 | 前场极高接待要求 + 后场极高保密要求 | 专业、稳重、可信 |
| **信托 / 银行私行 / 家办** | 高净值个人及家族 | 私密性 + 尊贵感 + 长期关系 | 私密、温暖、克制的奢 |
| **国资产融平台** | 政府、国企、金融机构 | 政务接待规格 + 市场化形象双重需求 | 端正、地域叙事、有分寸的气派 |
| **量化 / 自营 / 对冲** | 几乎不接待外客 | 交易环境 + 人才吸引 | 锐利、技术感、黑与冷 |

**判断动作**：任何项目开工前先问一句"**这个空间一年里有多少客户会进来？**"
- < 50 人次/年 → 钱全部投在员工体验（协作区、光、静音、家具）。
- 500+ 人次/年 → 钱按 6:4 投在前场（接待—会客—会议）与后场。
- 政务接待属性 → 必须有一条"领导流线"（专梯 → 贵宾接待 → 大会议）与员工流线不交叉。

## 二、面积配比基准

| 功能 | PE/VC | 券商资管 | 律所 | 私行/家办 | 国资产融 |
|---|---|---|---|---|---|
| 前厅 + 接待等候 | 5–8% | 4–6% | 6–9% | **8–12%** | 7–10% |
| 会议 + 会客 + 路演 | 16–22% | 14–18% | **20–26%** | 18–24% | 18–24% |
| 开放工位区 | 38–48% | **48–58%** | 32–42% | 25–35% | 38–46% |
| 独立办公室 | 10–16% | 6–10% | **18–26%** | 12–18% | 12–18% |
| 休闲 / 协作 / 茶水 | 8–12% | 7–10% | 6–9% | 8–12% | 8–12% |
| 后勤 / 机房 / 档案 | 6–10% | **10–14%** | 8–12% | 6–9% | 8–12% |

**人均面积（含分摊）**
| 业态 | ㎡/人 | 说明 |
|---|---|---|
| PE / VC | **15–25** | 人少钱多，最舒展 |
| 家办 / 私行 | 18–28 | 更舒展，会客位多于工位 |
| 律所 | 12–18 | 合伙人独立办公室占比高 |
| 券商资管 | 9–14 | 交易区密度高 |
| 国资产融 | 12–18 | 受国资面积标准约束，需核对当地规定 |

**会议室配比（这个业态最容易被低估的一项）**
- 资管类：**每 8–12 名员工配 1 间会议室**（普通企业是 1/20–25）。
- 会议室尺寸分布建议：2–4 人小会 **40%**、6–8 人 **30%**、10–14 人 **20%**、20 人+ 大会/路演 **10%**。
- **必配**：电话亭/静音舱（每 15–20 人 1 个）、1 间可视频路演的可变大空间。
- 律所另需：**独立客户会议区**（客户不进入办公区即可完成会谈）+ 谈判室（可分可合）。

## 三、造价档位（元/㎡，装修 + 机电，不含家具与弱电设备）

| 档 | 造价 | 能做到什么 | 典型 |
|---|---|---|---|
| D | < 2,000 | 矿棉板 + 涂料 + 地毯，标准写字楼 | 分支机构 |
| C | 2,000–3,000 | 局部造型、成品隔断 | 常规甲级装修 |
| **B** | 3,000–4,500 | 前场有木饰面与灯槽，后场标准 | 大多数券商分公司 |
| **A** | 4,500–7,000 | 主导线成立、发光面、定制家具、细部干净 | **弘毅 / 植德 / 国信这一档** |
| **S** | 7,000–12,000+ | 通高楼梯、边庭、整体石材、艺术品预算充足 | Antares、顶级 PE 总部 |

**分配原则（A 档项目的典型分配）**
- 前场（前厅、电梯厅、会客、大会议、走道）占造价 **45–55%**，占面积仅 20–25%。
- 后场（工位、后勤）用 B 档做法即可，**不必内疚**——植德就是这么做的。
- **家具单列**：A 档 1,800–3,500 元/㎡，S 档 3,500–6,000 元/㎡。
  资管空间的椅子是客户唯一会用身体判断的材料，**椅子预算不许砍**。
- **艺术品**：主件 ≥ 总造价 1.5%；A 档项目至少 1 件真作品，不用装饰画行货。
- **灯具**：占造价 8–12%（一般办公只有 5–6%）。资管空间的钱有很大一部分是花在光上的。

**几个单项造价参考（用于快速判断某个想法做不做得起）**
| 做法 | 元/㎡ 或 元/项 | 备注 |
|---|---|---|
| 整体发光弧墙 | 3,000–5,000 元/㎡ | 性价比最高的高潮点 |
| 弧形木饰面天花 | 1,800–3,200 元/㎡ | 双曲面 ×1.6 |
| 木格栅天花 | 900–1,800 元/㎡ | 顺直 vs 折面差价大 |
| 白色水磨石（现浇） | 600–1,100 元/㎡ | 镜面抛光另加 15% |
| 微水泥 | 400–800 元/㎡ | 需注意开裂风险 |
| 黑金花/雅士白大板 | 1,500–4,000 元/㎡ | 岩板可降至 600–1,200 |
| 通高钢木楼梯（两层） | **60–150 万元/部** | 含钢结构、木踏板、超白玻栏板 |
| 超白夹胶玻璃栏板 | 2,500–4,500 元/㎡ | 12+12，无立柱做法取上限 |
| 玻璃砖内幕墙 | 2,000–3,500 元/㎡ | 弘毅那种做法 |
| 劈斧面石材墙 | 1,200–2,500 元/㎡ | 人造替代品可降一半 |
| 定制金属丝艺术装置 | 8–30 万元/件 | 植德红丝/银丝那类 |

## 四、五档水位速判（Benchmark 的核心动作）

| 档 | 判据（四条全中才算） |
|---|---|
| **S** | ① 有一个不可复制的空间事件（通高楼梯/边庭/发光弧墙/内幕墙）② 主导线在平面与天花上完全重合 ③ 材料一次到位、细部无败笔 ④ 有真艺术品 |
| **A** | ① 主导线清晰 ② 冷暖关系成立（暖 25–40%）③ 有 1–2 个记忆点 ④ 拼缝干净 |
| **B** | 干净但无事件；换个 logo 也成立 |
| **C** | 有堆砌（多纹理/多主导线/暖材超 50%），或前后场混乱 |
| **D** | 材料档次与造价错配，或抄形式没抄逻辑 |

**报档位时必须同时说清"升一档缺的那一件具体的事"**，例如：
> 「这个方案在 A 档下沿。升 A+ 需要的不是加材料，是把茶水吧从平面中段挪到走道尽端，
> 变成整层唯一的黑块面兼视线终点——**这件事不加钱，只改平面**。」

## 五、气质谱系（用来跟业主对齐"我们要往哪个角走"）

两轴四象限。给业主看这张图，让他指一个点，比给他看 20 张意向图有用得多。

```
                 锐利 / 技术感
                        │
        量化自营 ●       │       ● 券商资管
                        │
  冷 ──────────────────┼────────────────── 暖
                        │
        PE / VC ●       │       ● 私行 / 家办
                        │        ● 国资产融
                 人文 / 温度
```

- **冷 × 锐利**：黑 8%、纹理用"格"、镜面与玻璃多、无木或极少木、灯光 4000K。
- **冷 × 人文**：弘毅所在的位置。木在顶、冷在地、自然跳色、3000K。
- **暖 × 锐利**：铜金 + 黑石 + 深木，国信会客室那一路。
- **暖 × 人文**：家办、私行，皮革与织物比例提高，但仍受 §1 约束（暖 ≤ 45%）。

**四个案例的坐标**：弘毅（冷·人文）｜植德（冷·中性偏锐）｜国信（前场冷·人文，会客暖·锐利）｜Antares（冷·锐利偏人文）。

## 六、全球标杆与可引用的参照

**事务所（提案时可作为对标口径）**
- 国际办公专项：**Gensler、HOK、SOM（金融总部）、M Moser、Bergmeyer、TPG Architecture、Studio O+A**
- 欧洲克制系：**David Chipperfield（材料克制的天花板）、John Pawson（极简的极限）、Vincent Van Duysen（暖极简）**
- 亚洲：**如恩 Neri&Hu（东方叙事 + 材料对比）、CCD、集艾、AIM、Robarts Spaces 一工、大观 DAGA**
- 日本克制系：**Nendo、Schemata、Suppose Design Office**（纹理与密度的功课去这里做）

**引用规则**：给业主/评标做参照时，**只引用同业态案例**。
拿酒店或美术馆的图讲资管办公，会被专业评委扣分。
如需引用非同业态，必须明说"这里只借它的一个做法：×××"。

**内部资料**：《全球证券资管办公室内设计案例集》系列（第三辑：殿堂门厅与新经典材质 20 例）
是本技能推荐的一手素材来源；Antares 即出自第三辑第 19–21 页。

## 七、合规与硬约束（做资管容易被忽略的六条）

1. **保密**：会议室隔声 ≥ **Rw 45 dB**（律所/并购业务要求 50 dB）；
   玻璃隔断需双层夹胶 + 空腔，单层玻璃达不到。
2. **视线保密**：交易区、并购项目组区域**不得从公共走道直视**；调光玻璃（雾化）是标配。
3. **档案**：律所/资管纸质档案需独立房间 + 甲级防火门 + 门禁记录，面积按 0.4–0.8 ㎡/人估。
4. **门禁分级**：前场（客户可达）/ 中场（员工）/ 后场（涉密项目组、交易室、机房）三级。
5. **交易区/机房**：UPS、精密空调、防静电地板、独立回路；净高需额外扣 200–300 mm。
6. **国资项目**：需核对当地《党政机关办公用房建设标准》或国资监管的面积/装修标准
   （常见约束：处级办公室 ≤ 18 ㎡、装修标准限额），**投标前必须先查，这是废标级风险**。

## 八、Benchmark 报告的标准结论句式

> 「本项目属于 **〈子业态〉**，面积 〈X〉 ㎡、〈Y〉 人，人均 〈Z〉 ㎡，
> 处在业态 **〈档位〉**。配比上 〈某项〉 偏离基准 〈±N%〉，建议 〈调整〉。
> 造价水位对应 **〈A/B/S〉 档**，与当前设计意图 〈匹配 / 高配 / 低配〉。
> 升一档需要的那一件事是：**〈一句话，具体到位置与做法〉**。」
